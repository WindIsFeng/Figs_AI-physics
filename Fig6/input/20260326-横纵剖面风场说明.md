| -------- | --------------------------------------- | ------------ | ------------ |

| `lon`    | `[south_north\|141]`                    | degree_east  | 经度（常数） |

| `va`     | `[bottom_top\|49] x [south_north\|141]` | m/s          | V风分量      |
