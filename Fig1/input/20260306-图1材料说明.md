## 第3项

图1第3项，20250923-1900的最内层区域风场数据：

`uv10_d05_2025-09-23_19UTC.nc`文件，包含2025年09月23日19时4个变量（10m高度处u和v、经度和纬度）的数值，维度大小均为`Dimensions and sizes:   [south_north | 141] x [west_east | 183]`。

使用下述python命令即可读取该数据文件：

```python
import xarray as xr
ds = xr.open_dataset("uv10_d05_2025-09-23_19UTC.nc")

# 四个变量对应的变量名："U10", "V10", "LAT", "LON"。（字母均为大写）
```
