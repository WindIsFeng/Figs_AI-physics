# 图3所需材料说明

总说明：

1. 算例类型有`aurora`、`era5`、`era5_no_lcz`、`era5_no_lcz_no_srtm`、`fengwu`、`fuxi`、`graphcast`、`pangu`，共计8种。预报类型有`24h`和`48h`，共计2种。
2. 数据文件中，数据保留到小数点后第4位。
3. 共处理了30个站点，见文件`selected_anemometers_elevations.txt`文件。其中，每行依次为站点简称和站点风速表海拔高度。站点简称由2-3个字母或者2个字母加1个数字组成（如kp、bhd、cp1等）。
4. UTC时刻中，零点零分表示为0000，而不是2400。



文件夹`1-站点风速风向`中为站点模拟值和观测值、风速和风向的时程数据。其中：

1. 文件夹`results_obs_newT`中为风速和风向观测值数据。文件夹中`max_wspd_obs.csv`、`mean_wdir_obs.csv`和`mean_wspd_obs.csv`分别为1分钟最大风速、1分钟平均风向和1分钟平均风速的观测值数据文件。数据文件中，第一列为UTC时刻，时间段为20250921 2200-20250924 1000，从第二列开始为站点数据，列名为站点简称。
2. 文件夹`results_sim_newT`中为风速和风向模拟值数据。文件夹中文件命名格式为：`[算例模型]_max_wspd_sim_[预报类型].csv`、`[算例模型]_mean_wdir_sim_[预报类型].csv`和`[算例模型]_mean_wspd_sim_[预报类型].csv`，分别为1分钟最大风速、1分钟平均风向和1分钟平均风速的模拟值数据文件。数据文件中，第一列为UTC时刻，从第二列开始为站点数据，列名为站点简称。

注：初步选择的典型站点为，海边橫瀾島wgl，平原濕地公園wlp，山地大帽山tms和城市中心京士柏kp。



文件夹`2和3-u和v数据`中为u和v风数据：

1. 文件夹`results_uv_obs`中为u和v观测值数据。在处理缺值时，若1分钟平均风速或风向出现32767则直接令u和v为缺值。文件夹中`u_obs.csv`和`u_obs.csv`分别为u和v观测值数据文件。数据文件中，第一列为UTC时刻，从第二列开始为站点数据，列名为站点简称。
2. 文件夹`results_uv_sim`中为u和v模拟值数据。文件夹中文件命名格式为：`[算例模型]_u_sim_[预报类型].csv`和`[算例模型]_v_sim_[预报类型].csv`，分别为u和v的模拟值数据文件。数据文件中，第一列为UTC时刻，从第二列开始为站点数据，列名为站点简称。
3. 文件夹`results_uv_err`中为u和v观测值减去模拟值计算的误差。文件夹中文件命名格式为：`[算例模型]_u_err_[预报类型].csv`和`[算例模型]_v_err_[预报类型].csv`，分别为u和v的误差数据文件。数据文件中，第一列为UTC时刻，从第二列开始为站点数据，列名为站点简称。
4. 文件夹`results_uv_rmse`中为u和v均方根误差。文件夹中`u_rmse_[预报类型].csv`、和`v_rmse_[预报类型].csv`分别为u和v的均方根误差数据文件。数据文件中，第一列为算例类型，从第二列开始为站点数据，列名为站点简称。



文件夹`4-站点风速展平`中为站点展平数据：

1. 文件夹`results_obs_newT_flattened`中为站点展平观测值数据。文件夹中`max_wspd_obs_[预报类型]_flattened.csv`、`mean_wdir_obs_[预报类型]_flattened.csv`和`mean_wspd_obs_[预报类型]_flatteneds.csv`，分别为1分钟最大风速、1分钟平均风向和1分钟平均风速的站点展平观测值数据文件。数据文件中，第一列为UTC时刻，第二列为站点展平数据。
2. 文件夹`results_sim_newT_flattened`中为站点展平模拟值数据。文件夹中`max_wspd_sim_[预报类型]_flattened.csv`、`mean_wdir_sim_[预报类型]_flattened.csv`和`mean_wspd_sim_[预报类型]_flatteneds.csv`，分别为1分钟最大风速、1分钟平均风向和1分钟平均风速的站点展平模拟值数据文件。数据文件中，第一列为UTC时刻，从第二列开始为不同算例模型的站点展平数据，列名为算例模型名称。

注：站点展平时按照站点简称字母顺序首尾相接。
